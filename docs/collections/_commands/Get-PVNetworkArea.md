# Get-PVNetworkArea

## SYNOPSIS
Lists all of the Network Areas that are defined in the Vault.

## SYNTAX

```
Get-PVNetworkArea [<CommonParameters>]
```

## DESCRIPTION
Exposes the PACLI Function: "NETWORKAREASLIST"

## EXAMPLES

### EXAMPLE 1
```
Get-PVNetworkArea
```

Lists all network areas
