# Stop-PVPacli

## SYNOPSIS
This command terminates PACLI.
Always run this at the end of every working
session.

## SYNTAX

```
Stop-PVPacli [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Exposes the PACLI Function: "TERM"

## EXAMPLES

### EXAMPLE 1
```
Stop-PVPacli
```

Ends the PACLI process
