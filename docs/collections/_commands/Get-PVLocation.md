# Get-PVLocation

## SYNOPSIS
Generates a list of locations, and their allocated quotas.

## SYNTAX

```
Get-PVLocation [<CommonParameters>]
```

## DESCRIPTION
Exposes the PACLI Function: "LOCATIONSLIST"

## EXAMPLES

### EXAMPLE 1
```
Get-PVLocation
```

Lists the locations defined in the vault
