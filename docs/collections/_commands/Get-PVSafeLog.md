# Get-PVSafeLog

## SYNOPSIS
Generates a log of activities per Safe in the specified Vault.

## SYNTAX

```
Get-PVSafeLog [<CommonParameters>]
```

## DESCRIPTION
Exposes the PACLI Function: "SAFESLOG"

## EXAMPLES

### EXAMPLE 1
```
Get-PVSafeLog
```

Lists activities per Safe
