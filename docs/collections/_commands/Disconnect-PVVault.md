# Disconnect-PVVault

## SYNOPSIS
This command enables log off from the Vault

## SYNTAX

```
Disconnect-PVVault [<CommonParameters>]
```

## DESCRIPTION
Exposes the PACLI Function: "LOGOFF"

## EXAMPLES

### EXAMPLE 1
```
Disconnect-PVVault
```

Logs off from vault
