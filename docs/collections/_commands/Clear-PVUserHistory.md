# Clear-PVUserHistory

## SYNOPSIS
Clears the history records for Users of the specified Vault

## SYNTAX

```
Clear-PVUserHistory [<CommonParameters>]
```

## DESCRIPTION
Exposes the PACLI Function: "CLEARUSERHISTORY"

## EXAMPLES

### EXAMPLE 1
```
Clear-PVUserHistory
```

Clears the history records for Users of the Vault
